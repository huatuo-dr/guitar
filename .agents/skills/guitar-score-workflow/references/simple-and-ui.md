# 简易谱与阅读界面

以下是当前项目默认行为，后续用户可以调整。简易谱从完整音乐数据投影生成，不另维护一份失去拍点关系的纯歌词。

## 简易谱配置

共享构建在非 `fingerstyle` 且存在 `simpleScore` 时启用切换。配置参考 `score/houlai.json`、`score/kongxin.json`；bar/beat 均指原始书写坐标。

| 配置 | 用途 |
| --- | --- |
| `fullSections: [段落起始小节号, ...]` | 指定整个段落保留完整谱面，不是逐个小节列表 |
| `fullRanges: [{start, end, name?}, ...]` | 精确保留过门、尾奏或部分器乐范围，包括单小节 |
| `routeVerses: [0, 1, ...]` | 与 `route` 段数一致，每段选择从 0 开始的歌词行；不能用“是否重复”代替真实遍次 |
| `lyricBreaks: [{bar, beat, kind, verse?}, ...]` | `space` 分隔短语，`line` 开新段；可按歌词行分别设定，落点须为现有 token |

### 必须保留的音乐关系

- 按 `route` 展开反复与跳尾，每小节每次实际出现都可定位。使用 `simpleSections()` 的 `barIds`，不要按段落编号推断出现次数；第二房子可能是首次出现。
- 真正双行的小节选择指定行，第二行空位不回填第一行。只有整小节为单行时，才复用公共歌词。沿用 `projectSimpleBar()`，不修改原始事件数组。
- 器乐段即使含弱起或收尾歌词，也保留完整内容；不要仅凭“有歌词”认定它属于简化区域。
- 演唱段允许跨小节、跨书写段落连接词句。断句多数用空格，语义大段才换行；不要每小节或每句强制另起一行。
- 和弦与歌词按原始拍点合并；无新歌词的换和弦仍保留独立落点。字下与独立下划线均为 2px；独立位置用全角空格 `\u3000` 加同样文字下划线，保持一个汉字的宽度。
- 完整保留的 SVG 使用原始上下文绘制，核对切分边界的拍号、延音、连线。

## 当前页面约定

- 顶部品牌“小k吉他练习”，有“返回曲谱库”；段定位显示段名与小字小节范围。
- “切换为简易谱／完整谱”按钮在每行小节/缩放提示下方，绿色底白字；不显示“当前：完整谱／简易谱”。
- 简易谱的标题到正文之间只保留和弦指法速查；隐藏标注图例与原谱演奏路线，没有“已按演奏顺序展开……”帮助段落。
- 简易演唱正文不显示小节号、范围、主歌/副歌段名和房子文字；器乐标题可保留。小节 ID 与导航仍保留。
- 简易歌词不受每行 2/4 小节或谱面缩放影响，设置仅影响保留的器乐谱。完整谱的小节号在小节开始左上角，不增加逐拍序号。
- 模式、缩放、行数和滚动速度按曲目分别记忆，存储不可用时仍可操作；更换阅读模式不应重置自动滚动。
- 自动滚动按钮固定显示“滚／停”，用户手动滚动或到达底部都不退出运行状态；长按选择五档速度。
- 打印用 A4 纵向、每行四小节、适应纸张，输出当前完整/简易模式，结束后恢复屏幕设置。打印按钮与下载按钮使用同样的中性配色。
- 下载按钮在各自曲谱中、紧接打印按钮。导出保留初始完整 HTML 与两种模式的数据；在新存储环境离线重开验证。
- 原生 SVG 页在禁用 JavaScript 时仍能阅读四小节完整谱；《偏爱》依赖 alphaTab 运行时，不把这条回退能力误写成所有曲目都有。
