# 记谱与数据约定

## 共同语义

- 六线谱最上方是 1 弦（最细弦），最下方是 6 弦；音符 `string` 沿用此编号。和弦图的 `frets` 数组则按 **6 弦到 1 弦** 保存，`-1` 表示不弹，`0` 表示空弦。
- 同一竖列的多个音符是同一事件；同一事件的弦号须唯一。用户只说“某个音应换弦”时，先按小节、拍点、相邻音和品位定位目标事件，检查换弦后是否与同列现有音冲突。和弦图说明按法，不能据此给指弹事件补上原图没有的音。
- 区分 × 的位置和图例：弹唱谱弦线上的 × 可表示按当前和弦拨指定弦；和弦图的 × 表示不弹；《偏爱》`fret: "x"` 表示闷音。不要统一转成休止或闷音。
- 《偏爱》的 `*` 经用户确认为打板，作为事件文字保存，不增加标称时值。其他来源中的同形符号应看其图例。
- 同音弧线通常为延音，不重新拨弦；H/P、滑音必须保留起止音。空白品位也可能有延音事件、符干或叠加音，不能因没印数字就删掉时值。
- 相似小节逐音核对尾音、装饰音和技法，不整段盲目复制。原生 SVG 曲目的书写顺序与演奏顺序分开记录：完整版保留反复与房子，`route` 明确实际路线。《偏爱》当前是用 `repeatOf` 展开的 61 小节谱，没有 `route`。

## 原生 SVG 构建链

`scripts/build-accompaniment.mjs` 当前读取 `score/<id>.json` 和 `score/<id>-vocal.json`，经 `attachVocals()` 与 `validateScore()` 后生成 HTML。无歌词的指弹也使用 `-vocal.json` 保存原图简谱；若新原谱没有该声部，不要编造，应按需求扩展构建入口。

| 数据位置 | 当前约定 |
| --- | --- |
| `patterns` | 可复用事件序列；`d8/u8/h8/a8` 为下扫/上扫/延续/琶音的八分事件，`h` 不是击弦 |
| `bars` | 连续 `number`、`pattern` 引用、`chords: [[拍点, 名称], ...]`；拍点从 1 开始 |
| `kind: "pluck"` | `strings` 指按和弦拨弦；`notes` 可记录同列额外明确品位，不能与 `strings` 重复弦号 |
| `kind: "fretted"` | `notes: [{string, fret, ...}]` 表示明确弦品的指弹事件；`tieToNext` 等技法字段记在起音上 |
| `kind: "hold"` | 延续前音；`sourceArrow` 可保留原图箭头，不等于重新扫弦 |
| `sections` / `route` | 书写段落范围 / 实际演奏路线，二者不必一一对应 |

简谱事件用 `degree`、`octave`、`duration`、`lyrics` 保存音级、八度、时值和逐音歌词；`degree: 0` 为休止，`hold` 为延续。`accidental` 使用 `b/#/n`。双行歌词放在同一事件的 `lyrics` 数组，空位置保持空，不把后面的字前移。变拍号小节要在伴奏 `bar.beats` 和简谱 `vocal.beats` 两侧同时写实际拍数，例如 2/4 两侧均为 `2`。

以四分音符为一拍时，当前 `eventBeats()` 的时值为 `4 / duration × 附点系数 × 三连音系数`。单附点是 1.5，双附点 1.75，`tuplet: 3` 为 2/3。简谱装饰音放在主事件的 `grace` 数组，不另占标称拍数。伴奏与简谱每小节分别合计，并与声明的 `beats` 一致。当前伴奏校验支持 2/4、4/4；新材料超出此范围时扩展支持，不能强行凑四拍。

六线谱与简谱按共同时间点对齐；三连音按每拍 960 ticks 归一化。指弹旁边的旋律简谱不一定逐音对应每次拨弦，只有来源明确对应时才作逐音音高相等断言。原图缺和弦图时，不把常见指法冒充原图；必要的补充参考使用已有 `reference: true` 和 † 机制，并记录依据。

## 《偏爱》的 alphaTab 构建链

`scripts/build.mjs` 合并分段 JSON，生成 `score/score.alphatex` 和 HTML。`remaining.json` 中 `repeatOf` 引用的小节在构建时克隆；修改被引用小节时要核对哪些重复段确实应随之改变。

- 原数据是 `bar.beats[]`，每个元素是一次事件，不一定一拍；同响音放 `notes[]`。AlphaTex 用 `品位.弦号`。alphaTab 解析模型的弦索引方向相反，回读测试通过 `7 - string` 比较。
- `legato: true`、`slide: "legato"` 放在起音上；`tie: true` 放在延音后续音上。这与原生 SVG 的 `tieToNext` 起点字段不同，不直接复制字段。
- `tuplet: [3, 2]`、`grace: true` 与原生 SVG 结构不同。装饰音可能从前音借播放时间，书写时值检查 `displayDuration`，不能为凑齐 `playbackDuration` 改谱。
- `arpeggio: "up"` 当前转换为 AlphaTex `ad`，方向以既有 SVG 与参考图核对，不能只按英文名称反转。
- 括号延音品号通过 `scripts/alphatab-display.mjs` 的受检查补丁显示；不要改为幽灵音来伪造外观。库升级需重新核查补丁及效果带布局。
- 附歌词用 `scripts/pianai-lyrics.mjs` 的独立落点映射，不为排歌词改动原指弹音符。

新旧版本混用时，按用户要求分别映射伴奏、旋律、歌词、器乐段和反复结构。先记清新旧乐句对应关系，再替换所需声部；保留弱起、跨小节延音和目标版本拍号。当前《后来》的混合版本是既有实例，不是其他曲目的默认编配。
