范围为「截图/小节信息.txt」指定的第 1–4 小节。逐音识别弦位、品位、时值、击勾弦、闷音、泛音及扫弦。原图标明 4/4 拍及 Capo fret 2；没有提供曲名与速度，不编造曲名，不提供带有推测速度的播放功能。红色虚线是否只是练习标记已询问用户。

使用 alphaTab 1.8.4 绘制 SVG 六线谱，保留节奏符干与连梁。白底、深色谱线，每行四小节为桌面默认布局，提供缩放、打印、小节定位。独立 HTML 内嵌乐谱、库和字体，不依赖服务器或联网。保留结构化转录与生成脚本便于校正及后续扩充。
